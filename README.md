# 🏢 Python B2B Lead Enrichment Tool

A lightweight, high-performance Python script to extract company metadata, technology stacks, firmographic intelligence, and email deliverability status from target domains.

Powered by the **[B2B Domain Profiler API](https://rapidapi.com/Huebercool/api/b2b-domain-profiler)** on RapidAPI.

---

## 🚀 Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt
export RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py

DOS
set RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py

Shell
$env:RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py
